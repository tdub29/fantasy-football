## Why this is captured rather than wired in

The repo has offense defense-vs-position in `site/data/sos-grid.js`, built by
`projections/build_sos_grid.py`. It has no IDP equivalent, so this fills a real gap.

It is NOT wired into the site, for two reasons:

1. **The scoring is not ours.** These are "balanced" ranks, and yuH pays 1.0 a solo tackle, 0.5 an
   assist, 3.0 a sack, 5.0 an interception and 3.0 a pass defensed. A DvP table under someone
   else's weights will disagree with our own lineup math, which is the exact class of bug the IDP
   scoring fix on 2026-09-16 removed.
2. **It is a scrape of a rendered page**, so it cannot refresh itself and would go stale silently.

The plan instead is `projections/build_idp_dvp.py`, deriving the same table from Sleeper's
historical weekly stat lines (`/stats/nfl/<season>/<week>`, which carry `solo`, `ast`, `sack`,
`int`, `pass_def`, `ff`, `fum_rec` per player plus the opponent), scored with **each league's own**
weights via `leagueScorePoints`. Same signal, self-refreshing, and correct per format.

This file is the cross-check for that build: when the derived table exists, the LB ordering should
broadly agree with the ranking above, and a large disagreement is a bug in one of them.

## Vegas tackle props

Checked 2026-09-16: not available on the key-free board this repo uses. BettingPros exposes only
season award futures (`most-tackles` id 57, `most-sacks` 56, `most-interceptions` 47) and its
game-level `interceptions` market (id 101) is a quarterback throwing them, not a defender recording
one. So there is no market line to devig for tackles, and the IDP projections stay model-based.
