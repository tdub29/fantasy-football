# Lane `overall`: addendum 1 (2026-10-05, written before any forecast was scored)

The prereg leaves these points open or infeasible as written. Each is fixed here before any C0, K0,
M1 or P1 number exists. None changes the target, formats, window, gates, rating scale, tiers or panel.

1. **Season points.** nflverse regular-season player totals (`stats_player_reg_{y}`), which are the
   sum of the weekly regular-season lines, rescored with each league's `leagueScorePoints` weights:
   pass_yd, pass_td, pass_int, rush_yd, rush_td, rec, rec_yd, rec_td, fumbles lost (sack + rushing +
   receiving) and the three 2-point conversion columns. Postseason excluded. Where a raw column is
   missing, nflverse `fantasy_points_ppr` is the fallback and the count is reported.
2. **Position for replacement.** The player's nflverse roster position that season, else the stats
   file position; FB counts as RB. Only QB/RB/WR/TE seasons enter the lineup fill. A draftee is
   valued at his DRAFT position's replacement only if he played there; otherwise at the position he
   was listed at that season (the lineup slot he would actually fill).
3. **Never-played draftees** have VOR3 = 0. Unlinked draftees (no college record) stay in the
   population with every profile feature missing and an `unlinked` flag.
4. **UDFAs.** nflverse `players` rows with no draft pick, not in `draft_picks`, position QB/RB/WR/TE/FB,
   `rookie_season` 2008-2023, linked to a college record by the builder's `link_college` (espn id,
   then name + final season + school) with draft year = rookie season. Pick = 262. The main tables use
   drafted players only; every metric is also reported with UDFAs added. The rating reference is
   drafted players only (prereg section 5).
5. **First scored class.** Expanding window, class Y trained on classes 2008..Y-1, so the first
   scored class is 2012 (four training classes). Scored classes 2012-2023. Sensitivity: an embargoed
   window (train on classes <= Y-3, whose three NFL seasons were complete at draft Y) for the
   headline pooled Spearman.
6. **Features.** `model_feature` is stored only for experiment runs and the latest one misses two
   relabelled 2008-2009 picks, so features are recomputed in-process with the builder's own
   `prepare()` / `career_features()` (same code, same inputs). Per position the profile set is the
   shipped `FEATS[pos]` plus `draft_age` and `early` (age/declare) where not already in it, a
   missingness flag for every feature, and an `unlinked` flag. Medians are imputed from the training
   window only.
7. **Model forms.** C0: isotonic regression of VOR3 on pick, decreasing, per position. M1: per
   position, ridge (RidgeCV, alpha chosen by internal CV on the training window only) on a cubic
   spline basis of log pick plus the standardized profile set. P1: the same without the log pick
   basis. Predictions floored at 0.
8. **K0.** Matched to the population by normalized name within position and class. Metrics are on
   the K0-covered subset, with M1/C0/P1 recomputed on the same subset; sensitivity: uncovered players
   tied last. K0 has no VOR scale, so its MAE is not reported. Snapshots: 2019 archive 2019-04-23 /
   2019-04-30; 2020 archive 2020-04-21 / db 2020-04-26; 2021 db 2021-04-28 / 2021-05-07; 2022 db
   2022-04-22 / 2022-05-06; 2023 db 2023-04-21 / 2023-05-05.
9. **Metric definitions.** Spearman, NDCG@24 (gain = realized VOR3) and precision@24 are computed
   per class and averaged over the classes in a resample; per-position Spearman is per class and
   position. The 75th percentile of VOR3 is pooled over drafted 2008-2023 per format; "above" is
   strict. MAE is pooled over the rows of the resampled classes.
10. **Gates.** Decided on F1 (the primary format); F2 and F3 are reported. The K0 comparisons use the
   point estimate on 2019-2023, K0-covered subset. "Beats C0 in >= 90% of resamples" means the
   paired M1-C0 pooled Spearman difference is > 0 in at least 1800 of 2000 resamples.
11. **Rating reference.** Out-of-sample expected VOR3 exists for classes 2012-2023 only (2008-2011
   have no prior classes), so the reference is drafted QB/RB/WR/TE 2012-2023. Percentile = share of
   the reference strictly below plus half the ties. Ratings come from the gated (published) forecast;
   M1 values are shown beside them in the panel.
12. **Current players.** 2026 draftees: trained on all classes 2008-2023, real picks. Upcoming classes
   (2027, 2028): profile through the last completed college season (2025), class = max(2027,
   hs_class + 3), P1 fit on all drafted classes 2008-2023. P1 is trained on drafted players, so it
   ranks draftable profiles; it is not a draft probability.
13. **Expected-VOR3 interval** for panel players: 5th-95th percentile over 200 class-bootstrap refits
   of the gated forecast.
14. **Pre-draft rating reference.** A P1 rating, if the pre-draft gate allows one, is the percentile
   of P1 expected VOR3 within the out-of-sample P1 expected VOR3 of drafted 2012-2023 players, so a
   profile-only number is never placed on the capital-informed scale. (Added before scoring.)
15. **Scoring weights** are read from each league's `scoring` block in `site/data/leagues.js`, with
   `leagueScorePoints` defaults for any key the block lacks.
