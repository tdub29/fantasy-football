# Independent review: A10 at RB (and the population A harness), 2026-10-04

Reviewer: a fresh agent (Opus) that did not build the harness, read-only on tracked files.

## Verdict: REJECT. A10 RB is not promoted; the draft-only baseline stays at every position.

The numbers reproduce exactly and the harness has no leak, but rule 6 fails.

1. **Reproduction: PASS.** RB fwd 0.4671 to 0.4576, bootstrap 96%, slope 0.93, 2020+ 0.4314 to
   0.4273, LOCO 0.4397 to 0.4265, reproduced, and again by an independent fold loop. Minor: the logged
   `sources_sha256` changes when current-season files refresh after 24 hours, so it cannot pin inputs
   on its own (results identical).
2. **Harness leakage: PASS** for fold masks and embargo, fold-local preprocessing, identical rows and
   RB feature timing (college cutoff draft year minus 1 for all 370 rows; no roster listing in or
   after the draft year).
3. **Selection leakage: FAIL (design, not code).** The v1 RB feature set, C and the 15-pass floor were
   pruned by leave-one-class-out on every class, 2020-2023 included (model card, "Read these" item 1),
   so every forward test class and every LOCO class fed feature selection. A10 was registered after
   the v1 holdout had been read (A0 RB lost it by 0.0022), so rule 4 is not independent evidence.
4. **Robustness: FAIL.** Classes 2015 (+33.3e-4) and 2017 (+54.4e-4) carry 92% of the gain; dropping
   either takes the bootstrap to 86-88% (rule 3 fails). The 2020-2023 gain is +0.0040 on 77 players
   (player-level bootstrap 64%). Seeds stable (95.1-96.5%). Every blend weight 0.2-0.8 passes, so A10
   is A0's signal shrunk toward the baseline, not an independent result.
5. **Multiplicity: REVIEW.** In a null simulation (talent features keep their link to pick, residual
   shuffled within class), an A10-type blend passed all five numeric rules 2.2% of the time at RB and
   4.5% at WR; across 36 correlated tests the chance of at least one null pass is roughly 15-50%.
6. **A0 sanity: PASS.** A0 matches the v1 card.

## Consequence

Every population A reject stands (the selection leak can only flatter v1-feature candidates). The
honest test of college features plus capital is to redo feature selection inside each training fold
(registered as A14, addendum 6), or to wait for the frozen prospective entries: 53 RB predictions for
the 2024-2026 classes are in `prospective-2024-2026.json`, scoreable from about January 2027.
