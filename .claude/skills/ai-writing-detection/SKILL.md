# AI writing detection (resume and professional writing)

## When to use

- Drafting or revising resume bullets, summaries, cover letters, or networking messages
- The user asks for human-sounding copy, to avoid AI detection, or less generic LLM phrasing
- A final pass before submitting application materials

## Workflow

1. Read the pattern list in [references/ai-writing-detection.md](references/ai-writing-detection.md).
2. Check transition-specific tells in [references/transitions-ai-tells.md](references/transitions-ai-tells.md).
3. Run the self-check steps at the end of the main reference (read aloud, colleague test, sentence-length variety).
