# Nudge: Save More Tomorrow Escalation

## When to Use

Use when present-tense pain blocks a good future contribution:

- 401(k), IRA, HSA, taxable, or emergency fund escalation.
- Raise-linked savings increases.
- Annual auto-increase settings.
- Side-income sweep rules.

## Framework

Save More Tomorrow lets users commit now to save more later, often when income rises. It uses inertia for good and avoids framing the increase as a current loss.

## How to Apply.

1. **Set starting contribution.**
2. **Choose escalation trigger.** Raise, annual date, bonus, debt payoff, or income milestone.
3. **Choose increment.** Percentage point, fixed dollar, or share of raise.
4. **Set cap.**
5. **Design opt-out.**
6. **Project path.** Show future rates/dollars.
7. **Set reminder copy.**

## Output Format

```markdown
## Save More Tomorrow: {plan}

Starting contribution:
Trigger:
Increment:
Cap:
Opt-out:
Projected path:
Reminder copy:
```

## Common Failure Modes

- **Immediate-loss framing.** Asking for more today triggers resistance.
- **No cap.** Escalation feels unsafe.
- **Hidden increases.** Users feel tricked if reminders are unclear.
- **No income trigger.** Escalation collides with tight cash flow.
