# Galef: Bias Thought Experiments

## When to Use

Use when the same facts might be judged differently under a different label:

- "My stock" vs a competitor's stock.
- Current vendor/product vs a new entrant.
- Consensus inside the team feels suspiciously comfortable.
- The user is harsher on one side than the other.

## The Framework

Galef recommends forcing thought experiments that change perspective while holding the relevant facts constant. The point is not clever hypotheticals; it is noticing whether motivation changes the judgment.

## The Five Tests

1. **Double Standard Test.** Would you judge this differently if another person/team/company did it?
2. **Outsider Test.** What would a new owner or adviser do?
3. **Conformity Test.** If nobody else believed this, would you still believe it?
4. **Selective Skeptic Test.** Are you applying a higher evidence bar to one side?
5. **Status Quo Bias Test.** If this were not already the default, would you choose it now?

## How to Apply

1. **State the current judgment.**
2. **Run all five tests.**
3. **Mark changed answers.** Any shift is a bias signal.
4. **Name the motive.** Identity, sunk cost, comfort, group, or ego.
5. **Correct the judgment.** Write the belief after the flip.
6. **Choose next action.** Research, ooch, update, exit, or hold.

## Common Failure Modes

- **Pretend imagining.** The user answers without actually inhabiting the flipped case.
- **Irrelevant flips.** The hypothetical changes too many facts.
- **One-test shopping.** Running only the test that flatters the current view.
- **Status quo invisibility.** Defaults feel like neutral reality rather than a choice.
