# Decisive: Narrow-Frame Audit

## When to Use

Trigger when the decision frame itself may be too small:

- The user is stuck between two choices.
- A question is phrased as "whether or not."
- A stock, SMB, or product decision has one favored path and one default rejection path.
- The user is debating endlessly without expanding the option set.
- The decision ignores what else the same time, money, or attention could do.

Don't trigger for: weighing a fully built option set. Use this first, then use Duke or stock-review skills.

## The Framework

### Core Thesis

The Heaths call narrow framing the first villain of decision making. We often define choices too narrowly and then do high-quality analysis on a bad option set. The corrective move is to widen before deciding.

### Whether-Or-Not Alarm

Any "whether or not" decision is suspicious. It hides opportunity cost and makes the current option look like the whole world.

### Opportunity Cost

Every option consumes money, time, attention, or risk budget that could be used elsewhere. Make the next-best use explicit.

### Vanishing Options Test

If the current options disappeared, what else could you do? This forces the mind out of the frame.

### Adviser View

Ask what a decision adviser would say if they were not emotionally attached to either option.

## How to Apply

1. **Quote the current frame.** Write the decision exactly as stated.
2. **Flag the frame type.** Whether-or-not, A/B, yes/yes, or already wide.
3. **Name the scarce resource.** Cash, time, attention, risk budget, relationship capital, or calendar.
4. **Run opportunity cost.** What else could the same resource do?
5. **Run Vanishing Options.** If the current choices were unavailable, list 3 alternatives.
6. **Add AND options.** Find combinations, staged paths, or partial commitments.
7. **Remove sham options.** Delete fake choices included only to make one option look good.
8. **Restate the improved decision.** Use a wider frame before analysis continues.

## Common Failure Modes

- **Whether-or-not trap.** The question is framed around one option instead of the problem.
- **Fake third option.** A weak strawman is added to make the preferred option feel balanced.
- **No opportunity cost.** The user asks "Can I afford this?" but not "What else could this buy?"
- **A/B tunnel.** Two choices feel exhaustive because they are emotionally salient.
- **Analysis too early.** The user wants diligence before the option set is wide enough.
