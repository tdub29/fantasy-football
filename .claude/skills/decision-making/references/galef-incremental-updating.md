# Galef: Incremental Updating

## When to Use

Use when evidence should move a belief without turning it into drama:

- A thesis is weaker but not dead.
- A product assumption changed.
- An SMB diligence item shifts confidence.
- The user wants to track conviction over time.

## The Framework

Galef reframes being wrong as **updating**. Beliefs can move gradually. A good scout does not need to defend the old version or perform a total reversal.

## How to Apply

1. **State the prior belief.**
2. **Record prior confidence.** Use a percentage/range or qualitative band.
3. **List new evidence.**
4. **Estimate direction and magnitude.** Small, medium, large update.
5. **Write the new belief.**
6. **Translate to action.** No action, monitor, research, trim, add, pivot, or exit.
7. **Save the update.** Preserve the changelog for later resulting audits.

## Output Format

```markdown
## Incremental Update: {belief}

Prior belief:
Prior confidence:
New evidence:
Update direction:
Update size:
Updated belief:
Action implication:
Next evidence to watch:
```

## Common Failure Modes

- **Binary flip.** Treating new evidence as total validation or total invalidation.
- **Ego apology.** "I was wrong" becomes the point instead of the updated map.
- **No magnitude.** The belief changes but confidence does not.
- **Action leap.** A small evidence update produces a large portfolio/product action.
