# Draft-capital rating input

Derived only from drafted 2008-2023 rows in the completed overall study's cached overall_data.pkl, copied into this lane before takeover. Source columns: draft_year renamed year, pick, pos, vor3_F1, vor3_F2. No college features, proprietary consensus ranks or new outcomes copied. Original research DB/cache remains untouched. Targets are common three-year starter value above replacement in the study's 10-team PPR 1QB and superflex lineups; see prospect-model-db/notes/prospect-research/lanes/overall/prereg.md and addendum-2026-10-05.md.

The shipped C0 model is position-specific decreasing isotonic regression of that target on actual draft pick. Historical forecasts now train through class Y-3 so all three-year target seasons precede draft Y. The percentile reference pools these time-safe 2012-2023 forecasts across positions on a common target, not different position hit definitions. Current classes train only mature rows. Ratings are draft-capital percentiles, never overall talent, hit probabilities, dynasty values or a model superiority claim. QB cards show both formats. No pre-draft rating or fabricated projected slot; no UDFA surrogate score. Legacy classes without adequate historical training show unavailable.

This corrects the historical label-availability concern identified in prior study. Because reference forecasts now use the three-year embargo, numeric percentiles need not reproduce old non-embargoed panel values. The pooled2012-2023 percentile reference is a modern fixed benchmark, not a percentile that could have been known at each historical draft. No historical as-of percentile claim is made. Neutral percentile labels replace outcome-implying tier names. Existing overall model gates still fail; profile has not shown improvement over capital, and upcoming overall scores remain unsupported.

New input versions require a separate coverage/label review rather than silently replacing this mature artifact. Source SHA256 is written into capital-ratings.js by the builder. Future public model data refreshes rescore newly drafted model records against this documented fixed training artifact.
