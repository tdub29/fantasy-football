# Galef: Soldier vs Scout Lens

## When to Use

Use when the user needs to inspect their reasoning posture before deciding:

- A thesis feels threatened by new evidence.
- The user is defending a prior choice rather than mapping reality.
- A portfolio, product, or SMB decision has become personal.
- The user asks whether they are rationalizing.

## The Framework

Soldier mindset asks defensive questions: **Can I believe this?** when a claim is convenient, and **Must I believe this?** when a claim is threatening. Scout mindset asks **Is it true?** and tries to make the map match the terrain.

## How to Apply

1. **Name the belief under pressure.**
2. **Identify the current question.** Is the user asking Can I, Must I, or Is it true?
3. **Spot defensive language.** Look for dismissal, ridicule, certainty, or identity claims.
4. **Rewrite as a scout question.** Make it concrete and evidence-seeking.
5. **Choose the next evidence move.** Outside view, ooch, stock review, dissent source, or pause.

## Output Format

```markdown
## Soldier / Scout Lens: {belief}

Belief under pressure:
Current mindset:
Current question:
Scout question:
Evidence being resisted:
Next evidence move:
```

## Common Failure Modes

- **Feeling objective.** The user feels fair-minded while filtering evidence defensively.
- **Facts as attacks.** Disconfirming information is treated as hostile.
- **Convenient skepticism.** Threatening evidence faces a higher bar than confirming evidence.
- **Premature routing.** The user wants another research pass when the real issue is defensive posture.
