# Galef: What the Soldier Is Protecting

## When to Use

Use when evidence is available but emotionally expensive:

- The user knows a thesis weakened but resists changing it.
- A product or SMB plan is failing but still defended.
- The user is protecting self-image, group belonging, or persuasive posture.
- A financial truth is postponed because facing it feels costly.

## The Framework

Galef argues soldier mindset often protects something useful: comfort, self-esteem, morale, persuasion, image, or belonging. The audit respects the payoff before asking whether the distortion is worth it.

## How to Apply

1. **Name the resisted truth.**
2. **Identify the protected payoff.** Comfort, self-esteem, morale, persuasion, image, belonging.
3. **Describe the distortion.** What belief is being bent?
4. **Price the distortion.** What decision gets worse if the user keeps it?
5. **Find a scout substitute.** How can the user preserve the legitimate need without lying to themselves?
6. **Choose one truth-facing action.**

## Output Format

```markdown

```

## Common Failure Modes

- **Mocking the motive.** The protected need may be real. Don't shame it.
- **Truth as austerity.** Scout mindset should solve for the need more cleanly, not just remove comfort.
- **Belonging blindness.** Group identity can be the hidden payoff behind a "rational" argument.
- **Persuasion confusion.** Sounding certain to others can leak into self-deception.
