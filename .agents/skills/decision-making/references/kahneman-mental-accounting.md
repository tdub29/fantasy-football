# Kahneman: Mental Accounting

## When to Use

Use when money is treated differently depending on its label:

- Brokerage funds feel separate from household funds.
- A refund feels spendable while debt remains.
- Bonus money gets riskier treatment.
- Budget envelopes block rational transfer.
- "House money" gains are gambled.

## Framework

Mental accounts help organize behavior, but they can violate fungibility. The audit asks whether account labels are useful guardrails or irrational barriers.

## Output Format

```markdown
## Mental Accounting Audit

Money/source:
Current account label:
Behavior caused:
Fungible alternative:
Useful guardrail or distortion:
Transfer/spend/invest rule:
```

## Common Failure Modes

- **House-money effect.** Gains feel less real and invite risk.
- **Refund windfall.** Returned money is treated as free.
- **Debt/investment separation.** Expensive debt coexists with low-return cash.
- **Over-correcting.** Some mental accounts are useful commitment devices.
