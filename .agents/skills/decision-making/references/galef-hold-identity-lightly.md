# Galef: Hold Your Identity Lightly

## When to Use

Use when a belief is no longer just a belief:

- A stock, strategy, product, or tool choice feels like identity.
- The user resists evidence because changing would threaten self-image.
- Labels are driving decisions more than outcomes.
- A team is fighting over camps despite shared goals.

## The Framework

Galef shows how beliefs become identities when they feel embattled or proud. Holding identity lightly does not mean having no values; it means making beliefs easier to update.

## How to Apply

1. **Name the identity label.**
2. **Run the eight-sign checklist.** Look for defensiveness, pride, outrage, group markers, sacred language, enemy images, status rewards, and unwillingness to steelman.
3. **Separate identity from impact.** What outcome matters if the label vanished?
4. **Run an ideological Turing test.** Can the user state the other side's view in a way they would recognize?
5. **Rewrite the belief lightly.** Convert "I am X" into "I currently think X because..."
6. **Choose an update-safe action.** Read dissent, run an ooch, change position size, or revisit later.

## Output Format

```markdown
## Hold Identity Lightly: {belief}

Identity label:
Eight-sign checklist:
Impact goal:
Other-side Turing test:
Lightweight belief rewrite:
Update-safe action:
```

## Common Failure Modes

- **Identity denial.** "It's just facts" when the language is tribal.
- **No Turing test.** The opposing view is caricatured.
- **Values collapse.** Holding lightly is mistaken for not caring.
- **Label fight.** The user protects the identity name instead of the desired outcome.
