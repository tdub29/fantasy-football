# Decisive: Multitrack Options

## When to Use

Trigger when the user needs more than one live path:

- A single option has become "the plan."
- Alternatives are being evaluated one after another instead of together.
- The user is emotionally attached to one ticker, acquisition target, or product feature.
- Options are just different sizes or tweaks of the same idea.
- The decision would benefit from a built-in fallback.

Don't trigger for: expanding a pure yes/no frame. Run `decisive-narrow-frame-audit` first if the decision is still binary.

## The Framework

### Core Thesis

Multitracking means considering several options simultaneously. The Heaths argue that parallel options improve learning, reduce ego attachment, speed decisions, and create fallbacks.

### Meaningfully Distinct

The options must be genuinely different. Changing a price target, trim size, or button color may be multitweaking, not multitracking.

### Fall in Love Twice

If only one option feels acceptable, the user is vulnerable to rationalizing flaws. Build at least two options good enough to choose.

### Sham Option Check

Remove options that exist only to make the preferred option look reasonable.

### Promotion and Prevention

Good multitracking often includes both growth-seeking and risk-reducing tracks.

## How to Apply

1. **Name the favored option.** Identify what the user is already leaning toward.
2. **Create parallel tracks.** Generate 2-4 meaningfully distinct options.
3. **Score distinctness.** Explain how each option differs in mechanism, risk, time, and upside.
4. **Remove sham options.** Delete strawmen and cosmetic variants.
5. **Balance mindsets.** Include at least one promotion-oriented and one prevention-oriented path when possible.
6. **Find a fallback.** Name what becomes easier if the favorite fails.
7. **Set learning questions.** For each track, state what it would teach.
8. **Choose next test.** Move the best 2-3 options into reality testing.

## Common Failure Modes

- **Multitweaking.** Options differ only cosmetically. Require mechanism-level differences.
- **Sequential search.** The user evaluates one option, rejects it, then starts over. Build tracks in parallel.
- **Single-track ego.** Criticism of the plan feels like criticism of the person. Multiple options reduce identity threat.
- **Sham option.** A fake alternative makes the preferred path look objective.
- **All offense or all defense.** Only growth bets or only risk reduction. Force a mindset balance.
